# Пускане с изграждане на празния слот и превключване

Кога: голяма промяна — нова версия на данните или схема, която иска преизчисляване
([deploy.md](../deploy.md), „Три пътя за пускане“). Живият слот не се пипа; връщането е превключване
обратно ([release-rollback.md](release-rollback.md)).

Всички записи в production са на човека, който пуска; правата са тези на production токена. Тежките
стъпки не са в ±30 минути около 00/06/12/18 UTC (обновяването и регистърът), не в нощта срещу неделя
(ходът на декларациите в 03:00) и не докато върви ход.

## Фаза 0 — настройките

В средата `production` в GitHub ([deploy.md](../deploy.md), §3): `SIGMA_D1_NAME` и `SIGMA_D1_ID` на
**живия** слот, `SUPPRESSION_SALT`, `SUPPRESSION_KEY_VERSION`. Запишете това, което иска наръчникът за
връщане („Какво да е записано преди пускането“).

## Фаза 1 — временният Worker

Actions → Deploy → Run workflow: `environment: production`, `component: rebuild-runner`. Качва се само
Worker-ът за изграждане (`apps/etl/wrangler.rebuild-runner.toml`): същият код и контейнер като ETL, един
работен поток `sigma-rebuild-cutover`, без график и без D1 binding. Създава се кофата за декларациите, ако
я няма, с правилата за изтичане. Проверката преди запис сверява настройките на живия слот. ETL-ът на
предишното издание продължава да обновява живия слот.

## Фаза 2 — изграждането на празния слот

```bash
wrangler workflows trigger sigma-rebuild-cutover '{"targetName":"<празен слот>","targetId":"<id>"}'
wrangler workflows instances describe sigma-rebuild-cutover <instance>
```

Етапите: `import` → `registry` → `precompute` → `declarations` → `search` → `ship` → `verify`. Празна кофа
за декларациите значи и пълно обхождане на регистъра на декларациите в етапа `declarations`. Прекъснат опит
продължава от последния завършен етап, ако се пусне с `"resume": true`; без него слотът се изпразва и
строи отначало. Изграждането може да е ден-два преди превключването: обновяването наваксва пропуснатите
дни след него.

## Фаза 3 — проверка на слота

- Ходът е `complete`: броят на редовете във всяка таблица съвпада със снимката и integrity gate е минал.
- Слотът носи версията на данните на кода и комита, от който е изграден:
  `wrangler d1 execute <слот> --remote --command "SELECT * FROM data_version"`.
- `node scripts/release-schema.mjs plan <слот>` — всички миграции са в журнала, паритетът е наред.

## Фаза 4 — превключването, в тих прозорец

1. В средата `production` в GitHub: `SIGMA_D1_ID` и `SIGMA_D1_NAME` → изградения слот.
2. Таг `v*`. Внедряването: проверката преди запис (версията на данните в слота е тази на кода), планът
   на схемата (празен), web, новият ETL с графика, тайните и правилата на кофата.
3. Изчистете кеша на `sigma.midt.bg` и проверете началната страница, списъците, договор, фирма, лице,
   търсенето и методологията.
4. Проследете първото обновяване и регистъра, после първия неделен ход на декларациите.

## Фаза 5 — след превключването

- Махнете временния Worker: `wrangler delete --name sigma-rebuild-runner`.
- Предишният слот остава непокътнат поне седмица — това е връщането назад.

## Времена

Измерено в Dev2 на 10–11.10.2026: празен слот, празна кофа за декларациите (както ще е на production),
живият слот с данните на v1.0.2. На Stage предстои.

| етап | Dev2 |
|---|---|
| `import` (поръчките от отворените данни) | ~30 мин |
| `registry` (партидите на изпълнителите) | ~30 мин |
| `declarations` с празна кофа: обхождане на регистъра на декларациите (~18 декларации/с) и разчитане | ~7 ч |
| `declarations` при вече изтеглен корпус (продължение с `"resume": true`) | ~50 мин |
| `search` | ~1 мин |
| `ship` + `verify` | ~20–25 мин |
| **изграждане от нулата, общо** | **~8,5–9 ч** |
| превключване (Фаза 4): проверка, план на схемата, web, ETL | ~3 мин (+1 мин тайните) |
| web по време на превключването | без прекъсване: всички заявки 200, стойностите сменят слота в един миг |
| връщане на web с `wrangler rollback` / пак напред | ~6 с / ~7 с, без грешка |

Прекъснато изграждане не губи часовете си: продължението с `"resume": true` взема слота с поръчките и
регистъра, а корпуса — от кофата.
